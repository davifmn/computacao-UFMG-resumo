Ordenação em $O(n \log n)$

Os três algoritmos que você precisa conhecer. Dois usam divisão e conquista (merge sort e quicksort) e um usa uma estrutura de dados esperta, o heap.

Merge Sort$n \log n$$n \log n$$n \log n$$O(n)$sim
Quicksort$n \log n$$n \log n$$n^2$$O(\log n)$ (pilha)não
Heapsort$n \log n$$n \log n$$n \log n$$O(1)$não

Por que $n \log n$? No merge sort, a recursão tem $\log_2 n$ níveis, e em cada nível as intercalações somam $n$ operações: $T(n) = 2T(n/2) + n = \Theta(n \log n)$. Isso também é o limite inferior para qualquer ordenação baseada em comparações: há $n!$ ordens possíveis e cada comparação dá 1 bit de informação, e $\log_2 n! = \Theta(n \log n)$.

O pior caso do quicksort: com o pivô sendo o último elemento e o vetor já ordenado, cada partição separa só um elemento e a recursão vira uma lista: $O(n^2)$. Clique em "Já ordenado" e compare as comparações. Na prática se usa pivô aleatório ou mediana de três.

O std::sort do C++ usa o introsort: começa com quicksort, troca para heapsort se a recursão ficar profunda demais (evitando o $n^2$) e usa insertion sort nos pedaços pequenos. Python e Java usam o Timsort (merge + insertion), que é estável e muito rápido em dados parcialmente ordenados.

O heap também é a base da fila de prioridade (std::priority_queue): inserir e remover o máximo em $O(\log n)$, usada no algoritmo de Dijkstra e em escalonadores.
