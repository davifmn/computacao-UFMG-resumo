SVD: uma imagem como soma de camadas

Uma imagem em tons de cinza é uma matriz. A decomposição em valores singulares a escreve como uma soma de matrizes de posto 1, da mais importante para a menos importante. Guardando só as $k$ primeiras camadas, temos uma imagem comprimida.

Os valores singulares

As primeiras camadas $\sigma_i\, \vec u_i \vec v_i^T$

A decomposição

Toda matriz $A$ ($m \times n$) pode ser escrita como

$$ A = U \Sigma V^T = \sum_{i=1}^{r} \sigma_i\, \vec u_i\, \vec v_i^T, \qquad \sigma_1 \ge \sigma_2 \ge \dots \ge \sigma_r > 0 $$

onde $U$ e $V$ têm colunas ortonormais e os $\sigma_i$ são os valores singulares. Geometricamente (lembra das transformações de GAAL?), toda matriz é uma rotação ($V^T$), seguida de um esticamento nos eixos ($\Sigma$), seguido de outra rotação ($U$).

Cada camada $\sigma_i \vec u_i \vec v_i^T$ é uma matriz de posto 1: um produto de uma coluna por uma linha, ou seja, uma "imagem listrada". O Teorema de Eckart–Young garante que truncar a soma nos $k$ primeiros termos dá a melhor aproximação de posto $k$ possível. Guardar $A_k$ custa $k(m + n + 1)$ números em vez de $mn$.

Onde a SVD aparece: análise de componentes principais (PCA), sistemas de recomendação (o prêmio Netflix), busca semântica em textos (LSA), mínimos quadrados estáveis (pseudo-inversa), redução de ruído e compressão de modelos de IA (low-rank adaptation, LoRA). O JPEG usa outra transformada (DCT), mas a ideia de "guardar só os componentes importantes" é a mesma.

A SVD desta página é calculada no seu navegador pelo método de Jacobi unilateral (numerico.js), que aplica rotações de Givens até as colunas ficarem ortogonais. Uma imagem enviada por você não sai do seu computador.
