## Dicas de quem já passou por aqui

- **Estruturas de Dados:** implemente tudo pelo menos uma vez, sem copiar. E desenhe os ponteiros no papel antes de escrever o código (é o que as visualizações fazem por você).
- **Bancos de Dados:** SQL se aprende escrevendo consultas. Faça os 12 exercícios do tutorial e depois invente perguntas sobre o banco de exemplo.
- **ALC + Cálculo II + Probabilidade:** as três se encontram em aprendizado de máquina (gradiente, mínimos quadrados, SVD, distribuições). Vale conectar os conteúdos desde já.
