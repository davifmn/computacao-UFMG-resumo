# Projeto `formas`

Projeto-exemplo de PDS II: hierarquia de classes com polimorfismo, compilação separada,
Makefile com dependências automáticas e testes de unidade.

```bash
make        # compila build/programa
make run    # executa
make test   # roda os testes (tests/teste_formas.cpp)
make clean  # apaga build/
```

O passo a passo completo está no [tutorial "Um projeto C++ de verdade, do zero"](https://davifmn.github.io/computacao-UFMG-resumo/periodo-02/programacao-e-desenvolvimento-de-software-2/tutoriais/projeto-cpp.html).
