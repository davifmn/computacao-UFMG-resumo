Por que a ordem 00, 01, 11, 10?

É o código de Gray: entre duas posições vizinhas muda um único bit, inclusive entre a última e a primeira. O mapa se comporta como um toro, e por isso grupos podem "dar a volta" pelas bordas (tente os quatro cantos com 4 variáveis!).

Dois 1s vizinhos diferem em uma única variável $X$, e $P\,X + P\,\overline X = P$: a variável some. É exatamente a simplificação algébrica, só que feita com os olhos.

Regras de agrupamento

  1. Grupos são retângulos com $1, 2, 4, 8$ ou $16$ células (potências de 2).
  2. Cada grupo deve ser o maior possível (grupo maior = termo com menos variáveis).
  3. Use o menor número de grupos que cubra todos os 1s. Grupos podem se sobrepor.
  4. Células X (irrelevantes, don't care) podem entrar num grupo se ajudarem, mas não precisam ser cobertas.

Um grupo que não cabe dentro de outro maior é um implicante primo. Se ele é o único a cobrir algum 1, é essencial e obrigatoriamente faz parte da resposta. Esta página calcula a resposta com o algoritmo de Quine–McCluskey (a versão tabular e programável do mapa) seguido de uma busca exata pela menor cobertura, então a expressão mostrada é sempre ótima.

Produto de somas: agrupe os 0s para obter $\overline F$ como soma de produtos e aplique De Morgan. Dá a forma mínima de $F$ como produto de somas.
