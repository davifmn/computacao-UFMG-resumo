Programação dinâmica: a tabela que lembra

Quando a recursão resolve o mesmo subproblema muitas vezes, guarde a resposta numa tabela e preencha-a numa ordem em que cada célula só depende de células já calculadas. Veja a tabela sendo preenchida, com as células de que cada valor depende, e depois a reconstrução da solução.

A receita

  1. Defina o subproblema numa frase. "T[i][c] = o melhor valor usando os itens 1..i com capacidade c." Se você não consegue escrever essa frase, não há tabela.
  2. Escreva a recorrência: como a resposta do subproblema vem de subproblemas menores. Em geral é uma escolha sobre o último elemento (levo ou não o item i? a última letra casa ou não?).
  3. Casos base: os subproblemas triviais (capacidade 0, string vazia).
  4. Ordem de preenchimento: qualquer ordem em que as dependências venham antes. Aqui, linha por linha.
  5. Reconstrução: guarde (ou refaça) as escolhas para devolver a solução, não só o valor.

Os três problemas

Mochila 0/1. $T[i][c] = \max(T[i-1][c],\ T[i-1][c - p_i] + v_i)$ se $p_i \le c$. O custo $O(nW)$ é pseudo-polinomial: polinomial no valor de $W$, mas exponencial no número de bits de $W$. Tanto que a mochila é NP-difícil. Na mochila fracionária (pode levar pedaços), o guloso por valor/peso é ótimo.

LCS. $T[i][j] = T[i-1][j-1] + 1$ se $a_i = b_j$; senão $\max(T[i-1][j], T[i][j-1])$. É o coração do diff e do alinhamento de sequências de DNA.

Distância de edição. $T[i][j] = \min(T[i-1][j] + 1,\ T[i][j-1] + 1,\ T[i-1][j-1] + [a_i \ne b_j])$: remover, inserir ou trocar o último caractere.

Memoização × tabela. A versão de cima para baixo (recursão + cache) só calcula os subproblemas realmente usados; a de baixo para cima (tabela) evita a pilha de recursão e permite economizar memória: para a LCS, basta guardar duas linhas, $O(\min(n, m))$.

Guloso × programação dinâmica

O guloso faz uma escolha e nunca volta atrás; a programação dinâmica considera todas as escolhas para cada subproblema. Use guloso quando provar que a escolha local está em alguma solução ótima (propriedade da escolha gulosa: Kruskal, Dijkstra, Huffman, seleção de atividades pelo menor término). Teste: na mochila 0/1 com capacidade 50 e itens (peso, valor) = (10, 60), (20, 100), (30, 120), o guloso por valor/peso leva os dois primeiros (160), mas o ótimo é o 2º + o 3º (220).
