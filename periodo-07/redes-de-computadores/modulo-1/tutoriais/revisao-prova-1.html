Folha de fórmulas

Atrasos (cap. 1–2)

Transmissão: $t_f = L/R$ (bits / bps)
Propagação: $t_p = d/v$ ($v \approx 2 \times 10^8$ m/s no cobre e na fibra; $3 \times 10^8$ no ar)
Bits "no fio": $R \cdot t_p$
Prefixos: kbps = $10^3$, KB = $2^{10}$ bytes

Capacidade (cap. 2)

Nyquist: $2B\log_2 V$   Shannon: $B\log_2(1 + S/N)$
$S/N = 10^{\text{dB}/10}$; a resposta é o menor dos dois
bps = baud × bits/símbolo
$\lambda f = c$; $\Delta f = c\,\Delta\lambda/\lambda^2$

Telefonia e comutação (cap. 2)

PCM: 8000 × 8 = 64 kbps; T1 = 193 × 8000 = 1,544 Mbps; E1 = 2,048 Mbps; STS-1 = 51,84 Mbps
Circuitos: $s + x/b + kd$
Pacotes: $x/b + (k-1)p/b + kd$; ótimo $p = \sqrt{hx/(k-1)}$

Códigos (cap. 3)

Detectar $d$: distância $d+1$; corrigir $d$: $2d+1$
Hamming: $(m + r + 1) \le 2^r$; verificação nas potências de 2; síndrome = posição
CRC: acrescenta $r$ zeros, divide por $G(x)$ (XOR), anexa o resto; detecta rajadas ≤ $r$

Janela deslizante (cap. 3)

$BD = R \cdot t_p / L$ (quadros)
$U \le \frac{w}{1 + 2BD}$; 100% com $w \ge 2BD + 1$
Parar-e-esperar: $\frac{t_f}{t_f + 2t_p}$
GBN: $w \le 2^n - 1$; SR: $w \le 2^{n-1}$

MAC (cap. 4)

M/M/1: $T = 1/(\mu C - \lambda)$; $N$ canais estáticos: $NT$
ALOHA: $S = Ge^{-2G}$ (0,184); com slots $Ge^{-G}$ (0,368)
Tentativas: $e^{G}$; slot de disputa: $2\tau$; quadro mín.: $2\tau R$
Ethernet: $\frac{1}{1 + 2BLe/cF}$; recuo em $[0, 2^i - 1]$

Pegadinhas

  • Nyquist × Shannon: um sinal binário nunca passa de $2B$, mesmo com S/N enorme (problema 2.4). E converta dB antes de usar Shannon.
  • Serviço × protocolo, sem fio × móvel, largura de banda em Hz × em bps.
  • Contagem de bytes inclui o próprio byte de contagem.
  • Bit stuffing: o 0 é inserido depois de cinco 1s dos dados, mesmo que o bit seguinte seja 0; a contagem recomeça depois do 0 inserido.
  • Hamming: os bits são numerados da esquerda e a partir de 1; o erro pode estar num bit de verificação.
  • CRC: acrescentar $r$ = grau do gerador (número de bits − 1) zeros, não o número de bits.
  • Checksum: o vai-um volta para o bit menos significativo (complemento de 1), e no fim ainda se inverte o resultado.
  • Janela: Go-Back-N usa $2^n - 1$, repetição seletiva $2^{n-1}$. E o "+1" do $2BD + 1$.
  • Tempo de ida e volta: no parar-e-esperar o ciclo é $t_f + 2t_p$ (com ACK desprezível); se o ACK vai de carona num quadro de dados, some mais um $t_f$ (problema 3.32).
  • Manchester: siga a convenção do livro (0 = baixo→alto) salvo se o enunciado disser outra; baud = 2 × bps.
  • ALOHA: $G$ inclui as retransmissões; $S = G\,P_0$.
  • Quadro mínimo Ethernet: 64 bytes do destino ao CRC (dados ≥ 46); o preâmbulo não conta.
  • MACA × 802.11: o MACA resolve o terminal exposto (quem só ouve o RTS pode transmitir); o 802.11 não (o NAV segura quem ouviu o RTS).
  • Ponte: aprende pela origem, decide pelo destino; destino na porta de chegada → descarta.
  • Sockets: LISTEN não bloqueia (o ACCEPT sim); ACCEPT devolve um socket novo; o cliente não precisa de BIND; TCP não preserva fronteiras de mensagens.
  • Malhas: barra cruzada = $N^2$ pontos e sem bloqueio interno; Banyan = $\frac{N}{2}\log_2 N$ comutadores, autorroteada pelos bits do destino, com bloqueio interno; filas FIFO na entrada → HOL → 58,6%; Clos sem bloqueio com $m \ge 2n - 1$.
