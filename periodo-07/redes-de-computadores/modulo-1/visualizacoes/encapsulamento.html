Encapsulamento: a viagem de uma mensagem pelas camadas

Cada camada trata o que recebe de cima como uma "caixa fechada" e põe sua própria etiqueta (o cabeçalho). No destino, cada camada tira só a etiqueta que a camada par colocou. Acompanhe uma requisição HTTP indo do host A ao host B através de um roteador.

O que guardar

  • Camada n do emissor ↔ camada n do receptor: elas conversam por um protocolo (comunicação virtual, horizontal). Os dados só se movem de verdade na vertical, até a camada física.
  • Interface: o que uma camada oferece à de cima. Serviço é o que ela faz; protocolo é como ela faz (as regras entre pares). Trocar o protocolo sem mudar o serviço não afeta as outras camadas.
  • Unidades de dados (PDUs): mensagem (aplicação) → segmento (transporte) → pacote (rede) → quadro (enlace) → bits (física).
  • Equipamentos: hosts implementam as 5 camadas; roteadores vão até a camada de rede; switches e pontes até a de enlace; hubs e repetidores só a física (seção 4.8.4).
  • Custo do empilhamento: cada cabeçalho ocupa banda. Com $n$ camadas de $h$ bytes cada e mensagens de $M$ bytes, a fração desperdiçada é $\frac{hn}{M + hn}$ (problema 1.16).

Na Fig. 1-15 do livro, a camada 4 da origem ainda pode fragmentar a mensagem (M → M1, M2) quando a camada de baixo impõe um tamanho máximo. Aqui, para simplificar, a mensagem cabe num único pacote.
