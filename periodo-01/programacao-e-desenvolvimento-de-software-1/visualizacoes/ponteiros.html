Ponteiros e memória

A memória é uma fileira enorme de caixinhas numeradas. Um ponteiro é uma caixinha que guarda o número (endereço) de outra caixinha. Execute o programa linha a linha e observe as setas.

Pilha × heap

Variáveis locais vivem na pilha: são criadas quando a função começa e destruídas automaticamente quando ela termina. Memória alocada com new vive no heap até que alguém chame delete. Isso dá liberdade (o dado sobrevive à função, e o tamanho pode ser decidido em tempo de execução), mas traz responsabilidade:

  • Vazamento de memória (memory leak): esquecer o delete.
  • Ponteiro pendente (dangling pointer): usar o ponteiro depois do delete.
  • Liberação dupla (double free): chamar delete duas vezes no mesmo endereço.

Em C++ moderno, prefira std::vector e smart pointers (std::unique_ptr), que chamam delete por você. Mas entender ponteiros "crus" é essencial para Estruturas de Dados: listas encadeadas e árvores são feitas de ponteiros.

Passagem por valor × por referência

Por que void troca(int a, int b) não troca nada? Porque a função recebe cópias. Com ponteiros, a função recebe endereços e pode alterar as variáveis originais:

void troca(int *a, int *b) {
    int tmp = *a;
    *a = *b;
    *b = tmp;
}
troca(&x, &y);   // em C++ também dá para usar referências: void troca(int &a, int &b)
